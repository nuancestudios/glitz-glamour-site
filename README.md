# Glitz & Glamour website

This folder contains the static website files for GitHub Pages. It uses relative asset paths, so it works at a GitHub Pages project URL such as `https://YOUR-USERNAME.github.io/glitz-glamour-site/`.

## Pages

Home · Academy · Services · **Testimonials** · Contact. (The old `#/portfolio` link still works — it now opens the Testimonials page.)

The Testimonials page is built from the 103 public Google reviews of *Glitz & Glamour Academy and Boutique Salon* (4.9 ★). Quotes are reproduced as written (trimmed with an ellipsis where a review continues), grouped by topic — bridal, salon & hair, Academy & students, long-standing clients — with the reviewer names and dates shown on Google. The full review text lives on Google; the page links out to the listing. Nothing on the page is invented copy, and no review ratings or names were altered.

## Publish it (no coding needed)
1. Sign in or create an account at https://github.com.
2. Click **+** (top right) → **New repository**.
3. Name it `glitz-glamour-site`; choose **Public**; click **Create repository**.
4. On the empty repository page, click **Add file** → **Upload files**.
5. Unzip the website package on your computer. Upload the files *inside* this folder (`index.html`, `styles.css`, `app.js`, `README.md`, and the `public` folder). Keep the folder structure as it is. Do not upload the zip itself.
6. Click **Commit changes**.
7. In the repository, open **Settings** → **Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**. Select branch **main** and folder **/(root)**, then click **Save**.
9. Wait a minute or two. Refresh **Settings → Pages** and open the link GitHub gives you.

If you see a 404 at first, give GitHub another minute and refresh. Keep `index.html`, `styles.css`, `app.js` and the `public` folder at the top level of the repository.

Before sharing publicly, confirm contact details and replace the clearly labelled art-direction placeholder images with client-approved photography.
